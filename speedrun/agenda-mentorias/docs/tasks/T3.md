# T3 · Listar vagas livres de um mentor

`GET /mentores/:id/vagas?data=YYYY-MM-DD` · arquivo: `src/rotas/vagas.js` · registrar em `src/app.js`

## Casos

| Quando | Status | Corpo |
|---|---|---|
| mentor não existe | 404 | `{"erro":"Mentor não encontrado"}` |
| `data` presente e não é uma data válida `YYYY-MM-DD` | 400 | `{"erro":"data inválida"}` |
| sucesso | 200 | `[{"id","inicio"}]` só vagas livres, ordenadas por `inicio` crescente; com `data`, só as daquele dia |

"Data válida" quer dizer formato `YYYY-MM-DD` **e** dia que existe no calendário.

## O Par

- ✅ **Funciona:** `GET /mentores/1/vagas?data=2026-11-16` → `200 [{"id":9,"inicio":"2026-11-16T08:00"},{"id":1,"inicio":"2026-11-16T09:00"},{"id":2,"inicio":"2026-11-16T10:00"}]`
- ❌ **Falha:** `GET /mentores/999/vagas` → `404 {"erro":"Mentor não encontrado"}`

## NFR-2 (desafio)

Com 1.000 vagas no mentor, p95 abaixo de 50 ms. Dica: cada chamada ao repositório custa uma ida ao banco (ADR-001).
